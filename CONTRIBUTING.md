# Contributing

See the [development guide](docs/DEVELOPMENT.md) for local tests, host integration points, and the manual verification checklist. Bug reports should include the add-on and host versions, Windows version, install method, the relevant generation or import step, and expected versus observed behavior. Reproduce with synthetic media when possible.

Send focused pull requests with regression tests for changes to cleanup, path routing, or export. Update both READMEs for changes to the user workflow. See [SECURITY.md](SECURITY.md) for sensitive reports.
