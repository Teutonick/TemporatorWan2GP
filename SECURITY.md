# Security reporting

Report suspected unintentional persistence, unsafe path handling, or access to another session's media through [private vulnerability reporting](https://github.com/Teutonick/TemporatorWan2GP/security/advisories/new) when available. For public reports, share only a synthetic reproduction. Omit real media, prompts, tokens, and personal paths.

Include the Temporator and WanGP versions, Windows version, the generation or import path, and where files remained after exit and restart.
