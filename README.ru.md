# TemporatorWan2GP

**Сохраняйте только те результаты, для которых нажали SAVE.**

[English](README.md) · [Лицензия MIT](LICENSE) · [Документация разработки](docs/DEVELOPMENT.md) · [Изменения](CHANGELOG.md)

Temporator — дополнение для веб-интерфейса [WanGP (Wan2GP)](https://github.com/deepbeepmeep/WanGP) на Windows. Оно помещает медиа поддерживаемых сценариев в отдельную временную сессию и добавляет **SAVE** под галереями **Media Generator** и **Edit**. WanGP запускается привычным способом.

## Установка

Требуются Windows и WanGP 19.292 или новее. Дополнение использует Python и Gradio из окружения WanGP.

1. Откройте **Apps & PlugIn Manager → Install from URL**.
2. Вставьте адрес репозитория и нажмите **Download and Install from URL**.

   ```text
   https://github.com/Teutonick/TemporatorWan2GP
   ```

3. Включите **TemporatorWan2GP** и перезапустите WanGP.

Если аддон раньше копировали вручную, сделайте резервную копию или перенесите его каталог за пределы папки `plugins` перед установкой по URL. Для обновления через менеджер WanGP нужна установленная Git-копия аддона.

## Генерация, предпросмотр и сохранение

1. Сгенерируйте или отредактируйте медиа в штатном интерфейсе.
2. Когда очередь завершится, выберите результат в галерее. Он доступен для просмотра и повторного использования до конца сессии.
3. Нажмите **SAVE**. Результат и распознанные сопутствующие файлы появятся в настроенной папке WanGP. Для workspace с выделенным хранилищем используется его папка.

Повторное сохранение идентичного комплекта использует уже существующую копию. При штатном завершении Python временная сессия удаляется. После принудительного завершения остатки удаляются при следующей загрузке аддона. Существующие и явно сохранённые файлы остаются на диске.

## Что входит в режим

| В пределах режима | Вне режима |
| --- | --- |
| Результаты и промежуточные файлы Media Generator и Edit, которые WanGP направляет через штатный механизм выбора выходной папки | Самостоятельные пути записи Media Flow, Motion Designer и сторонних дополнений |
| Загрузки и предпросмотр Gradio, стандартные временные файлы после активации | Кэш браузера, хранилища ОС, удалённые сервисы и другие процессы |
| Автосохранение очереди и папка сессий Deepy для текущего запуска | Headless CLI, отдельные процессы MCP/API, существующие данные и кэш моделей |

В течение сессии медиа записываются на диск. Очистка выполняется обычным удалением файлов. Подробнее в [отказе от ответственности](DISCLAIMER.md) и [политике сообщений о проблемах безопасности](SECURITY.md).

## Обновление

Нажмите **Update** в менеджере дополнений и перезапустите WanGP. При ручной установке замените файлы аддона файлами одной версии при закрытом WanGP. Механизм проверки обновлений описан в [руководстве по выпуску версий](docs/RELEASING.md).
